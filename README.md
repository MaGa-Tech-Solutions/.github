# .github

Special repository for the **MaGa Tech Solutions** GitHub organization.

The organization profile shown at [github.com/MaGa-Tech-Solutions](https://github.com/MaGa-Tech-Solutions) is rendered
from [`profile/README.md`](profile/README.md). Edit that file to update what visitors see on the org page.

Brand assets (hero banner, dividers, footer, logos, and service icons) live in [`profile/assets/`](profile/assets)
and are referenced from the README via `raw.githubusercontent.com` URLs pointing at the `main` branch — keep file
names stable or update the README when renaming. Palette matches the website: navy `#060a14`, cyan `#22d3ee` →
indigo `#818cf8` → violet `#8b5cf6`.
